# Teamwork Indiana — New Site Concept (GoHighLevel-ready)

A redesign concept for **TeamworkIndiana.com**, built to be rebuilt inside
**GoHighLevel** with every interactive element wired to GHL features and
automations.

## Files

| File | What it is |
|---|---|
| `index.html` | Self-contained homepage concept. Your real logo is embedded, works in light & dark, fully responsive. Open it in any browser. |
| `GHL-BUILD-GUIDE.md` | Step-by-step map of how to build this in GHL — brand kit, page sections, workflows, memberships, calendars, pipelines. |
| `logo.png` | Your logo (pulled from the current site) for the GHL Media Library. |
| `assets/web-flags.jpg` | Signing-day flags group photo (web-optimized, from your Drive marketing folder). |
| `assets/web-logowall.jpg` | Athletes at the Teamwork Bloomington logo wall (web-optimized, from Drive). |
| `assets/IMG_1013/1016/1017.PNG` | Real 5-star Google review screenshots (Rhett Good, Angela Lindauer, Chris Parker) used for the testimonials. |

> Note: the vector logo master (`SquareLogo.ai`) lives in your Drive folder
> "Teamwork Bloomington Marketing Files Logo etc" — upload it to GHL for
> print/large-format use. The photos include recognizable athletes (some
> minors): confirm you have photo releases before the site goes live.

## Try it

1. Open `index.html` in a browser.
2. Flip the **"Build view"** switch in the top nav — ⚡ badges reveal which GHL
   feature powers each button/form.
3. Toggle the theme with the moon icon; resize to see the mobile layout.

## What it keeps from the current site

Same message and structure — *"get faster & jump higher in 30 days"*, the
5-step method, the Five F's, membership pricing from $129, coaches, success
stories, Bloomington location — restyled around your logo's colors and set up so
leads, bookings, and payments run automatically in GoHighLevel.
